New Colombus

Vous prenez la direction d'une agence de la Colombus Cie. Votre équipe, vos clients et vos décisions : le voyage commence.

Cette agence a déjà une équipe. Pour la rejoindre depuis un autre appareil, saisissez le code d'équipe affiché sur l'écran de vos coéquipiers.

Un seul appareil par équipe suffit. Vos coéquipiers peuvent rejoindre la même agence avec le code d'équipe.
